## 🔬 AI/ML & LLM Core Interests

I actively explore and build systems centered around the modern AI ecosystem:

* 🗂️ **Retrieval-Augmented Generation (RAG):** Context-aware generation, advanced chunking strategies, hybrid search mechanisms, and multi-stage reranking.
* 🤖 **Agentic AI:** Developing autonomous agentic workflows utilizing tools, memory persistence, and multi-agent orchestration frameworks (LangChain, CrewAI, AutoGen).
* 🧠 **Deep Learning & Transformers:** Studying attention mechanisms, fine-tuning LLMs (PEFT, LoRA, QLoRA), and model architectures.
* ⚙️ **MLOps & AI Evaluation:** Implementing reproducible pipelines, data versioning, trackable experimentation, and robust LLM evaluation techniques.
* 📐 **AI System Design:** Building highly resilient, scalable backend infrastructures capable of handling heavy inference workloads with low latency.
